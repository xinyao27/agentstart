# Security policy

## Supported versions

Security fixes are released for the latest published version of AgentStart. Upgrade to the newest
release before reporting an issue that may already be resolved.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/xinyao27/agentstart/security/advisories/new)
to share the affected version, reproduction steps, impact, and any proposed mitigation. Please do
not open a public issue for an undisclosed vulnerability.

The maintainers will respond in the private advisory and coordinate disclosure after a fix is
available.
