# AgentStart 0.1.1

- Lets one agent coordinate others. A coordinator opens a run, files tasks, starts a worker for each
  task, and reads each worker's report back, all through the `agentstart` CLI — so a batch of work
  no longer has to be driven one terminal at a time.
- Gives every project a shared memory file that all of its worktrees and agents read and append to.
  A dispatched worker is handed its path, so background no longer has to be retyped into every new
  agent.
- Makes the `agentstart` browser commands reachable. They could not be dispatched at all before, so
  an agent had no way to drive Chrome; it can now read a page, click, fill, and screenshot it.
- Adds `agentstart computer open-app`, so an agent can launch an app that is not running rather than
  only recovering a window from one that already is.
- Adds a browser pane to the iOS app, with tab switching, so a session's page can be viewed and
  driven from the phone.
- Turns the workspace tool panel into a column that stays visible beside the content area, instead
  of an overlay that had to be dismissed to see the tab it had just opened.
- Closes the Chinese localization gaps that made parts of the interface fall back to English,
  including two option sets that mixed languages inside a single menu.
- Removes the keybindings the interface never dispatched and wires up the ones it already
  advertised.
- Stops a legacy panel width from overwriting the navigation sidebar, and removes the remaining
  panics on request paths.
- Hardens session history responses and refines UI theming.
