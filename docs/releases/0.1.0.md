# AgentStart 0.1.0

- Brings the Chrome extension, daemon, installers, macOS app, and iOS companion under the AgentStart
  name and release channels.
- Restores one-click workspace expansion from project rows.

  immediately after launch.

- Moves connection recovery, trusted sites, and community adapters into the main workbench settings.
