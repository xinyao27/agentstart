# AgentStart 0.1.4

- Updates a self-owned daemon without being asked. An installation that owns its own binary — the
  curl installer and the direct download — now checks for a release as the runtime comes up and
  installs it end to end, instead of waiting for a restart or a click in Settings. A check records
  itself and the next one waits twenty hours, so restarting the daemon is not a network call, and
  Homebrew, the npm shim, and the daemon inside the macOS app are left to their own channel.
- Stops running out of file descriptors. launchd hands the daemon a 256-descriptor soft limit and it
  ran at exactly that ceiling, so a busy workspace could fail unrelated opens — the "Too many open
  files" that left a workspace write unable to land. The limit now rises to the hard maximum before
  the runtime starts, worktree listings are shared between callers instead of spawning one `git
  worktree list` per project per poll, and a head poll that outlasts its own period no longer runs
  back to back.
- Reports the CLI as installed when the daemon is the command. A daemon started from its own
  `agentstart` binary — the npm shim, Homebrew, or the self-updating install — runs under a PATH
  that never contains the directory the command lives in, so the status card read "Not installed".
  The running command and the `/usr/local/bin` registration are now both recognized, and removing
  the running runtime from that card is refused instead of deleting the daemon's own binary.
- Keeps agent skill runs in step with the daemon. A restarted or swapped runtime left the skills
  subscription closed for the rest of the session, and a start the daemon accepted or refused with
  `already-running` was never re-read, so the remove dialog showed no progress and kept offering a
  button the daemon kept refusing. The subscription reopens and reports readiness, and the run is
  re-read after every start.
- Keeps a missed deadline out of the crash reports. The side panel's startup read is fire-and-forget
  across a chain of runtime calls, and a call that missed its deadline rejected the read with
  nothing left to consume it, which the renderer recorded as an app-root error. The local
  terminal-id exchange is now best-effort like its remote siblings, and the rejection is logged
  instead of escaping into a crash report.
- iOS scales with Larger Text and keeps one blurred layer per region. Every screen now sizes from the
  system text styles instead of fixed points, so Dynamic Type reaches the whole app; the sizes that
  remain pinned — the terminal grid, the diff gutter, the terminal chrome — each name why scaling
  would break them. Settings becomes its own tab root, controls inside panels are solid chips rather
  than a second blur, and status, diff, and selection meaning carries a label or shape as well as
  color.
- iOS stops spending alerts on failure. One banner per page carries the message, an optional retry,
  and a 44pt dismiss, and only the confirmations that need a decision stay alerts. Transport
  failures show product copy instead of Foundation's "operation couldn't be completed", the widget
  gets its own localized strings, dismissing a notification on the phone retires the same one on the
  daemon, and Home on iPad keeps its sidebar and detail columns for the whole session instead of
  rebuilding them on every tab switch.
