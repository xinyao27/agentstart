# AgentStart 0.1.6

- Stops busy terminals from flickering when several agents stream at once. Six agents painting their
  TUIs together could push terminal delivery past its provider buffer; every missed range then
  escalated to a full recovery frame, so a pane cleared and repainted several times a second while
  the daemon answered hundreds of model restores and no live output reached the renderer. A missed
  range now replays the terminal's own retained output, a recovery frame is only used when that
  history no longer reaches back, a background agent gets one stale-model notice per hidden stretch
  instead of one per chunk, and an acknowledgement that races a closed stream is an ordinary
  resubscribe rather than a pane failure.
- Puts the navigation sidebar behind a titlebar toggle. The worktree column now has a resident
  control in the shared header that writes the same state as the Toggle Sidebar shortcut; it leaves
  the titlebar while the browser's own side panel renders that navigation, and hiding the column can
  no longer strand a surface with no way to bring it back. Sticky worktree headers keep their
  occlusion color on every host.
- Names the browser tab after the selected workbench tab. The document title now follows the strip —
  terminal, browser, editor, and page labels — instead of repeating the worktree name, and falls
  back to the worktree when the strip has no selection.
- Reads OpenCode Go usage from the CLI's own API key. The usage window no longer depends on a
  hand-copied dashboard cookie: the daemon prefers the account-wide usage API using the key the
  opencode CLI already stores, and keeps the cookie scrape as the fallback for accounts without a key.
